# AI Resume Optimizer & ATS Analytics Dashboard

## Project Overview

AI Resume Optimizer is an AI-powered ATS (Applicant Tracking System) Resume Analysis web application developed using Python, NLP, and Streamlit. The application helps users analyze resumes against job descriptions, calculate ATS match scores, identify missing skills, and generate resume improvement suggestions.
The project combines Artificial Intelligence, Natural Language Processing, and Data Analytics concepts to create an interactive resume optimization dashboard.

## Technologies Used
Python

Streamlit

NLP (Natural Language Processing)

Scikit-learn

PyPDF2

Plotly

Pandas

OpenAI API (optional)


## Project Workflow
Upload Resume PDF

Extract Resume Text

Analyze Resume Keywords

Compare Resume with Job Description

Calculate ATS Match Score

Detect Missing Skills

Generate AI Suggestions

Visualize Insights on Dashboard
